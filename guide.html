简单、安全的内网穿透工具

🖥 部署服务端（Ubuntu）

1SSH 登录服务器，执行以下命令：
# 国内（宝塔） curl -sSL https://8.134.147.15:8888/down/UymNPEIDwxve.sh | sudo bash # 国外（GitHub） curl -sSL https://raw.githubusercontent.com/PhiRainking/nat-tunnel/main/server/install.sh | sudo bash

脚本自动完成：安装 Node.js → 写入服务端代码 → 配置 systemd → 开放防火墙

2安装完成后，浏览器打开管理面板配置：
http://你的服务器IP:9000

默认管理密码: admin123 | 可在面板中在线修改令牌和密码

自定义参数: PORT=7000 TOKEN=*** ADMIN_PWD=*** sudo bash install.sh

💻 下载客户端（Windows）

1下载安装包：
下载 Windows 安装包 NatTunnel-Setup.exe（约 115MB）
2运行安装程序，按向导完成安装

支持自定义安装目录、创建桌面快捷方式

3打开 NatTunnel，填写连接信息：
服务器地址: 8.134.147.15 端口: 7000 认证令牌: rainking-tunnel-2024

点击「连接」后即可添加 TCP/UDP 端口映射

🔗 工作原理

外网访客 → 服务器端口 → 加密隧道 → 你的电脑 → 本地服务
支持 TCP 和 UDP 协议。客户端通过控制端口与服务器保持长连接，服务器收到外部请求后通过隧道转发到你的本地服务。
